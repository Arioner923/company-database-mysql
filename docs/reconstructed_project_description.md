# Reconstructed Project Description

> **Important:** The original 2017 assignment statement is not available. The following description was reconstructed from the preserved ER diagram, relational model and SQL script.

Design and implement a relational database for a company with multiple branches. The company employs staff of different specializations and serves customers who place orders for products. Products are supplied by suppliers, potentially at supplier-specific prices.

The database should represent and store:

- company branches and their contact information;
- customers and their addresses;
- employees, their employment details and branch assignment;
- specialized employee categories such as technicians, accountants and secretaries;
- employee dependents/protected members;
- customer orders and the employee handling each order;
- products and their characteristics;
- suppliers and their contact information;
- products contained in orders;
- products offered by suppliers and the associated supplier price;
- branch/customer collaborations.

The design should be expressed as an ER model, converted to a relational model and implemented in MySQL with representative sample data and basic SQL operations.
